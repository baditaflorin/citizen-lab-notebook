# Security Policy

## Supported Versions

The `main` branch and the latest tagged release are supported.

## Reporting a Vulnerability

Please report security issues privately by email:

baditaflorin@gmail.com

Do not open a public issue for vulnerabilities that may expose user data or secrets.

## Security Model

Citizen Lab Notebook is designed as a static GitHub Pages application. It should not require runtime secrets, hosted credentials, or private backend services.
